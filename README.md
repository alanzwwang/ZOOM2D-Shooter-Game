A 2D side-scrolling shooter that runs in any modern browser, with 600 weapons, base building, destructible terrain and raids.

The game is in the **`Zoom2D Shoter Game Webpage`** folder. Open `index.html` in that folder to play. No install needed.

See that folder's README for the full feature list and version history.
